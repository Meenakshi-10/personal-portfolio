Projects

Systems & Storage

  • Separating Keys from Values in SlateDB
    Rust · MinIO · LSM-trees · Object Storage

    Implemented WiscKey-style key-value separation for SlateDB, a cloud-native LSM-tree KV store backed by object storage. Values above a configurable threshold are packed into immutable blob objects (identified by ULIDs), with (blob_id, offset, length) references stored in SSTables. Includes manifest-driven garbage collection via per-blob live-byte counters and a blob cache to mitigate read-path overhead. Reduced write amplification from ~6× to near 1× on write-heavy workloads across value sizes from 1 KiB to 1 MiB, benchmarked on MinIO.

  • Dynamic Maintenance of Clustering-Based Vector Indexes Active Research
    C++17 · FAISS · SIFT1M · ANN · IVF

    Researching how to keep a clustering-based (IVF) vector index accurate as vectors are inserted and deleted, without periodic full rebuilds. Implemented a streaming centroid perturbation policy inside FAISS that nudges cluster centroids incrementally with each mutation. Evaluating recall degradation over varied mutation schedules on SIFT1M (1M × 128-dim vectors) using precomputed ground-truth nearest neighbors. Collaboration with Prof. Ram, UIUC.

Information Retrieval

  • Search Engine for Short-Form Video Content
    Python · Qdrant · BM25 · GPT-4.1 · Whisper · Streamlit · FFmpeg

    End-to-end multimodal search engine for Instagram Reels. A scene-detection frame sampler using Sum of Absolute Differences (SAD) on grayscale frames selects only visually distinct frames for VLM processing. A video ingestion pipeline combines GPT-4.1 for visual description with Whisper for audio transcription, embedding results into a Qdrant vector store. Two-stage retrieval combines cosine-similarity vector search with BM25 re-ranking and a disparity-threshold filter, achieving precision@5 of 0.93 on a curated 50-query evaluation set.
